# Task 38 — Correzione Malus Gara e Dry-Run Ricalcolo Punteggi Storici

## OBIETTIVO

Correggere e verificare la logica del **Malus Gara** secondo il regolamento ufficiale di FantaMotoGP e preparare un dry-run completo del ricalcolo dei punteggi storici.

**QUESTO TASK DEVE ESSERE ESCLUSIVAMENTE READ-ONLY.**

L'obiettivo è capire esattamente quali punteggi cambierebbero prima di autorizzare qualsiasi modifica al database.

---

# 1. REGOLA UFFICIALE DEL MALUS

La tabella del regolamento rappresenta delle **soglie**, non valori distinti per ogni numero di NC.

La regola corretta è:

| Piloti pronosticati NC | Malus Gara |
| ---------------------: | ---------: |
|                      0 |          0 |
|                      1 |         -1 |
|                      2 |         -1 |
|                      3 |         -5 |
|                      4 |         -5 |
|                      5 |        -10 |

Quindi:

```text
0 NC      →   0
1–2 NC    →  -1
3–4 NC    →  -5
5 NC      → -10
```

## IMPORTANTE

Il numero di NC NON deve essere calcolato contando tutti i piloti `NOT_CLASSIFIED` presenti nei risultati ufficiali della Gara.

Deve essere calcolato esclusivamente sui **5 piloti pronosticati dall'utente**.

Per ciascuno dei 5 piloti pronosticati:

* se il pilota è presente nella lista `Out`/non classificati → conta come NC;
* se non è presente → non conta come NC.

Mantieni inoltre la logica già verificata nel Task 32 relativa a `L`:

> `L` conta i piloti pronosticati in Gara trovati nella stringa `Out`.

Non sostituire questa definizione con il semplice conteggio dei `NOT_CLASSIFIED` della sessione.

# 3. CORREZIONE DELLO SCORER

Se la logica attuale non applica correttamente le soglie, prepara la modifica necessaria affinché lo scorer utilizzi:

```text

  if (nc >= 5) return -10;
  if (nc >= 3) return -5;
  if (nc >= 1) return -1;
```
