# 4. PUNTI DEI SINGOLI PRONOSTICI

Questa è la correzione principale.

Attualmente:

`1116/1116 prediction_entries.points = 0`

Per ogni prediction completa, valorizzare `prediction_entries.points` con il punteggio corretto relativo a QUEL SINGOLO PRONOSTICO.

Esempio concettuale:

| prediction_type | position | rider   | points |
| --------------- | -------: | ------- | -----: |
| POLE            |        1 | Rider A |      5 |
| QUALIFYING_TIME |        — | —       |      3 |
| SPRINT          |        1 | Rider B |      3 |
| SPRINT          |        2 | Rider C |      1 |
| SPRINT          |        3 | Rider D |      0 |
| RACE            |        1 | Rider B |      5 |
| ...             |      ... | ...     |    ... |
| RACE_OUT        |        — | Rider X |      2 |

NON inserire un punteggio aggregato dentro una singola entry.

Ogni entry deve contenere esclusivamente i punti relativi a quella specifica entry.
